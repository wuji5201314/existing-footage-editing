# existing-footage-editing

一个给 AI 助手用的「已有素材剪辑」Skill：把一段现成的长视频（访谈、播客、直播、课程）剪成可直接发布的短视频——从转写选段到发布文案包，一条龙配齐。

## 作用

长视频剪切片，真正的质量差距不在剪辑工具，而在**选段**和**发布工作流**。这个 Skill 固化了一套经实战纠错的标准：

1. **转写是唯一事实源** —— 先用 faster-whisper 做带时间戳的转写（含幻觉过滤：纯音乐段落的低音量文本不可信），选段、切点、字幕、文案全部从转写出发
2. **语义完整压倒金句** —— 每条切片必须主语 + 前提 + 结论俱全，能独立成立；金句类切片 12–15 秒起步，绝不切"没头没尾的口号"（这是被真实用户打回重切后定下的标准）
3. **选段要打分** —— 先做内容盘点（观点/故事/数字/错误/方法/答疑），再按 6 维打分（独立性/2 秒钩子/单一观点/结尾落点/能量/说话人价值），≥8/12 才留
4. **计划先行** —— 先写计划文件（含冷开场、发布顺序），再动刀切
5. **切点要校验，不是靠眼睛看** —— 词边界落刀 + 语音截断自动校验/修复/二次校验，切点加 30ms 淡化防爆音
6. **BGM 预混，不信任平台叠加** —— 某些平台在编辑器里叠 BGM 会把视频压短（如抖音多选模式压到 6 秒），所以把 BGM 以 15% 音量预混进文件，上传时只开原声；BGM 只用用户自备音频，绝不抓取版权音乐
7. **交付的是发布包，不是散文件** —— 每条切片配齐：文件 + 标题 + 话题标签 + 置顶评论 + 封面（封面/标题/简介首行"三位一体"同承诺、选帧避开闭眼帧、320px 可读性测试）+ 排期，并记发布日志防重复

## 应用场景

- **访谈 / 播客切片**：几十分钟的对谈长视频 → 每天一条的金句/观点短视频（抖音、TikTok、Reels、Shorts）
- **直播回放高光**：从回放里定位并切出高光时刻
- **课程 / 讲座精华**：长课里提炼可独立传播的知识点片段
- **长视频批量拆条**：一条长内容拆成一组有排期、有文案的短视频矩阵
- **多版本分发**：同一批切片导出 GIF（聊天传播）/ 小尺寸 MP4（转发）/ 全清 MP4（平台发布）三版矩阵

不适用：从零生成动效视频（那是 [code-motion-video](https://github.com/wuji5201314/code-motion-video) 的事）；多机位精剪、电影级调色等专业 NLE 工作流。

## 硬标准速览

| 项目 | 标准 |
|---|---|
| 切片完整性 | 主语 + 前提 + 结论，金句类 ≥12–15s |
| 选段打分 | 6 维 ≥8/12 |
| 清晰度 | 以源文件为上限，如实告知，绝不假放大（如 576p 源就是 576p） |
| 字幕 | 源片已烧录字幕时绝不重复烧录 |
| BGM | 仅用户自备音频，人声 100% / BGM ≈15%，混后验电平 |
| 响度 | 按平台规范标准化（约 −14 LUFS） |

## 使用方法

把本仓库放进你的 Agent 的 skills 目录即可，例如：

```bash
git clone https://github.com/wuji5201314/existing-footage-editing.git ~/.claude/skills/existing-footage-editing
```

然后把长视频给 Agent，说「把这个访谈剪成切片发抖音」，它会按转写 → 盘点 → 打分 → 计划 → 切片 → 发布包的顺序执行。执行层的切割/混音/导出由 FFmpeg 完成，本 Skill 管选段、流程与发布。

**配套 Skill**：[ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)（kajisho5，`npx ffmpeg-skill` 安装）——后期执行层，提供本地 FFmpeg 工具链（probe → 剪辑 → 检查 → 验证），本 Skill 的切割、拼接、BGM 预混、响度与导出都通过它执行；两者分工是"本 Skill 管选段与发布，ffmpeg-skill 管动手"。

## 来源

核心经验沉淀自真实项目：52 分钟访谈长视频 → 7 条金句切片 + 3 条理论长片 → 抖音逐日发布的全过程（含被用户纠错重切、BGM 预混参数定版等实战教训）。

v2 融入了开源同类 Skill 的优秀做法（逐项出处与取舍记录见 `references/techniques.md` §13）：cutlist（打分/计划先行/封面三位一体）、video-agent-skills（内容盘点/冷开场/发布日志）、video-use（词边界落刀/切点自检）、ai-video-editing-skill（语音截断校验/幻觉过滤）、shorts-cutter（停顿压缩）、jianying-editor-skill（验收清单/低清代理）。
